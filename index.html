Adding a project

Open index.html and copy a .project-card block. Replace the SVG illustration with your image using:

  • 1 Add your image to the project folder, e.g. img/myproject.jpg
  • 2 Replace the <svg> block inside .card-visual with:
    <img src="img/myproject.jpg" style="width:100%;height:100%;object-fit:cover">
  • 3 Update the tag, title, and description text inside .card-info
  • 4 Save → commit → push to GitHub. Your live site updates in ~60 seconds.
